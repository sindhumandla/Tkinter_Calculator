# Calculator using Tkinter

A clean and beginner-friendly calculator application built using Python and Tkinter.  
This project features a modern dark-themed interface, smooth button interactions, and essential calculator functionalities designed with simplicity and usability in mind.

#  Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Backspace functionality to delete the last entered digit
- Clear button to reset the calculation
- Dark-themed, minimal user interface
- Grid-based layout for consistent alignment
- Error handling for invalid expressions

# Technologies Used
- Python
- Tkinter (Python GUI library)

# How to Run
1. Make sure Python is installed on your system
2. Clone this repository or download the source code
3. Run the file:
   bash:
   python calci.project.py
